# Agnes AI: генерация изображений текстом

## Когда использовать

- Концепт-арт локаций, персонажей, предметов для Dungeon2.
- Иконки, тайлы-текстуры, референсы, когда арт-пака KayKit недостаточно.
- Быстрые визуальные итерации.

Не использовать: видео (модель `agnes-video-2.5-flash` — вне скилла), image-to-image (не реализовано).

## Ключ (секрет, не публиковать и не коммитить)

Значение ключа **не хранится в этом файле** — оно лежит рядом, в `api-key.md`
(секретный файл, добавлен в `.gitignore`, на других машинах его нет).

Скрипт подхватывает ключ сам, в порядке приоритета: параметр `-ApiKey` → переменная окружения
`AGNES_API_KEY` → `api-key.md` в корне скилла (рядом с `scripts/`; файл парсится, ключ извлекается
автоматически). Сообщения об ошибках ключ не содержат.

Не переносить ключ в `SKILL.md`, скрипты, отчёты, ответы, git; не печатать значение в stdout.
Если ключа нет нигде (нет `api-key.md`, переменная не задана) — скрипт падает с кодом `2`
до любого HTTP-запроса.

## Быстрый старт

Вызвать скрипт (форма вызова проверена пробами; `-ExecutionPolicy Bypass` обязателен —
обычный запуск `.ps1` блокируется политикой):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File F:\WORK\Dungeon2\skills\agnes-image-gen\scripts\agnes-image.ps1 -Prompt 'stone dungeon wall tile, seamless texture, top-down view, minimal flat illustration' -Size 2K -Ratio 1:1 -Out F:\WORK\Dungeon2\art\dungeon-wall.png
```

`$env:AGNES_API_KEY` заранее задавать не нужно — достаточно `api-key.md`. Переменную стоит
задавать только если файл отсутствует (например, на чужой машине).

Параметры: `-Prompt` (обязательный), `-Size` (дефолт `2K`), `-Ratio` (дефолт `1:1`),
`-Model` (дефолт `agnes-image-2.5-flash`), `-Out` (путь к `.png`; без него печатается только url),
`-ApiKey`. Коды возврата: `0` успех, `1` ошибка API, `2` ошибка конфигурации (нет ключа, пустой prompt,
`ratio` вне списка). `ratio` принимает только `1:1 3:4 4:3 16:9 9:16 2:3 3:2 21:9` — валидируется локально.

## Контракт API

- База: `https://apihub.agnes-ai.com`, auth: `Authorization: Bearer <key>`.
- `POST /v1/images/generations`, тело `{model, prompt, size, ratio, extra_body: {response_format: "url"}}`.
  `extra_body.response_format` живёт **внутри** `extra_body`; на верхнем уровне — невалидно.
- Ответ: `{data: [{url, b64_json, revised_prompt}], created, task_id}`. Скрипт просит `url` и качает его.
- `GET /v1/models` — список моделей. Таймаут скрипта 300 с, генерация занимает ~10–15 с.

## Размеры

API принимает тиры `1K/2K/3K/4K` (или произвольный `WxH`), но **точный WxH не соблюдается**:
пропорция сохраняется, размер отмаштабирован (живой пример: `size=1024x768` пришло 1152×864).
Проверено живьём (модель `agnes-image-2.5-flash`):

| size | ratio | реальные пиксели |
|------|-------|------------------|
| 1K   | 1:1   | 1024×1024 |
| 1K   | 21:9  | 1568×672 |
| 2K   | 3:4   | 1728×2304 |
| 3K/4K | —    | не проверено |

Под точные пиксели Godot ресайзить придётся вручную — автресайза в скилле нет.

## Модели (`GET /v1/models`)

`agnes-image-2.5-flash` (дефолт, проверена), `agnes-image-2.1-flash`, `agnes-image-2.0-flash` — изображения;
`agnes-3.0-flash`, `agnes-2.5-flash` — текстовые; `agnes-video-2.5-flash` — видео (вне скилла).

## Ошибки и лимиты

- Генерация **не идемпотентна**: автоматические ретраи запрещены — каждый запрос создаёт новую картинку.
  При коде `1` показать причину (код и сообщение шлюзера) и спросить пользователя, повторять ли вручную.
- Лимиты сервиса не документированы; генерируй только под реальную потребность, не в циклах.
- Base64 (`b64_json`) — ловушка: ответ при `return_base64=true` весит сотни КБ. Никогда не печатать
  base64 в stdout, отчёт или контекст — только url и скачивание в файл.

## Фоллбэк: инструмент dsh

Если прямой HTTP недоступен (нет PowerShell/сети), установленный в dsh плагин `dsh-plugin-agnes-media`
даёт инструмент `agnes_image_generate`: `prompt`, `size`, `ratio`, `output=file|url|base64`, `saveDir`.
`output` всегда `file` или `url` — не `base64`. Основной путь всё равно прямой HTTP (работает в любом харнессе).

## Шаблон промпта под арт игры

```
<тип арта>, <стиль: low-poly flat, <палитра: серый камень, холодный синий свет, оранжевый факел>, <ракурс/композиция>, minimal flat illustration
```

Пример: `stone dungeon floor tile, low-poly flat, KayKit dungeon pack style, grey stone, top-down view, seamless, minimal flat illustration`

## Куда сохранять

- Референс (что смотрим и сверяем по нему, например рендер объекта для моделиста): `art/reference/<имя>.png`.
- Всё остальное (текстуры, иконки, арт под игру): `art/<имя>.png`.
- Пробы и черновики: `E:\Temp\opencode\` — не в репозиторий.
- `art/` Godot не импортирует автоматически (папка вне `game/`): если картинка идёт в игру как ресурс,
  положи её в `art/`, а рабочую копию положи в `game/assets/` (там появится `.import`).
