# Вход в торговый форпост: план реализации (ред. 3, продолжение)

> **Для исполнителей:** каждая задача — свежий исполнитель, затем отдельный ревьюер (AGENTS.md). Шаги с чекбоксами `- [ ]`.

**Цель:** Зона входа в форпост — блок породы с вырубленным залом, ворота-тоннель с решёткой, двор-яма со статуей основателя, караулка с рычагом, ход внутрь, реквизит, освещение, проверка в headless.

**Архитектура:** Отдельная сцена зоны `game/level/zones/gate_entrance.tscn` (`Node3D`), инстансится в `level.tscn`. Блок породы — один glb, сгенерированный скриптом Blender. Реквизит — реальные модели Hunyuan (`*_1024.glb`), поставленные со скалированием и коллизией. Механика: решётка — `AnimatableBody3D` + `portcullis.gd`; рычаг — `Area3D` + `lever.gd`, вызывает `portcullis.open()` через экспорт `NodePath`. Взаимодействие — физическая клавиша `E`.

**Технологии:** Godot 4.7.2, GDScript, Blender 5.2 (генерация блока породы), headless-проверки через `--script`.

**Спецификация:** `docs/current/2026-10-14-gate-entrance-v2/design.md`.

## Глобальные ограничения

- Пандус: ширина не меньше 4 м; порог ступени не выше 0.2 м.
- Свод купола: высота не ниже 3.5 м; проём решётки открыт не уже 3 м.
- Ход внутрь за караулкой: ширина не меньше 3 м.
- Пол: ровный, без вертикальных уступов выше 0.1 м; перепады — склоны не круче 45°.
- Капсула персонажа: радиус 0.35, высота 1.8.
- Клавиша взаимодействия: `E`, физическая.
- Рейнджер заморожен: `Character`, `FPSCamera`, `character_controller.gd` не меняются.
- Не трогать: пользовательские `MeshInstance3D` (ChainLink, Book1, Cage и др.), модули, `GridMap*`, `mesh_library.tres`, `art/**` (только читать), `.import`.
- Коммит не делать.
- Все пути в документах — относительные (от корня проекта).
