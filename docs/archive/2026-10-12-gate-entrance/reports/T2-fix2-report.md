## 2. Арка `arc_1024` — стоп: требования не сходятся (цифры)

Меш замерен пробой по треугольникам в системе корня glb (ширина X, высота Y, толщина Z; без масштаба, м):

- **AABB:** X −0.3902..0.3874 (ширина 0.7776), Y 0.0000..0.9099 (высота 0.9099), Z −0.1334..0.1239 (толщина 0.2573).
- **Сечение X=0 (центр проёма):** твёрдое Y 0.0000..0.0725 (порог-сильл), далее проём до **0.632**, перемычка 0.632..0.9097.
- **Ноги:** внутренние грани X −0.159…−0.173 и +0.155…+0.168 (сечения Y 0.10…0.60). Самое узкое место — на Y≈0.60: просвет −0.159..+0.155 = **0.314**. Выше ~0.63 просвета нет.

Пересчёт под рамку 3.8 м (сверено с сечениями):

| Требование брифа | Нужный масштаб | Что получается |
|---|---|---|
| Верх рамы 3.8 м | Y = 3.8 / 0.9099 = **4.176** | Свод (низ перемычки) = 0.632 × 4.176 = **2.64 м** (нужно ≥ 3.6) |
| Свод ≥ 3.6 м | Y = 3.6 / 0.632 = 5.70 | Верх рамы = 0.9099 × 5.70 = **5.18 м** (нужно 3.8) |
| Просвет ног ≥ 3.5 м | X = 3.5 / 0.314 = **11.15** | Внешние края ног на ±4.33 м (бриф: ±1.9). Радиус внешней вершины ноги ≈ **7.10 м** (внутри r = 7.2) |
| Ноги на ±1.9 м | X = 3.8 / 0.7776 = 4.89 | Просвет = 0.314 × 4.89 = **1.54 м** (нужно 3.5) |
| Ориентир «~1.2» (от 5.00 из T2) | X = 6.0 | Просвет = **1.88 м** (нужно 3.5) |

Вывод: ни одно растяжение не даёт одновременно верх 3.8, свод ≥3.6 и просвет ≥3.5. Вертикальное растяжение не лечит свод: толщина перемычки в модели 0.278 из 0.910 высоты, при верхе 3.8 она даёт низ 2.64. Ширина даёт просвет 3.5 только при X ≈ 11.15 — это 2.7× пропорционального 4.18, а не 1.2×. Модель `arc_1024` — проём около 0.31 × 0.56 м в своих единицах; под проём 3.5 × 3.6 её нельзя подогнать растяжением.

**Дополнительно (для решения):**
- Свод 2.64 м — это физическая высота прохода под рамой. Капсула игрока (1.8 м) проходит, но проём под требование T1 «≥3.5» не выполняет.
- Сильл 0.0725 × 4.176 = **0.30 м** — видимая ступень внутри проёма (коллизии у него нет).
- Решётка (верх 3.6) упирается в перемычку 2.64–3.8 при подъёме. Если коллизию перемычки ставить по AABB — решётка её пересечёт; проверка `решётка не пересекает коллизии` это поймает, когда арка появится.

Варианты для ведущего (не выбираю сам): (а) модель арки под проём 3.8 × 3.6 — новый glb, лучше всего; (б) растянуть до свода 3.6 (верх ~5.2 м) — купол на x≈5.5 даёт высоту ~4.7 м, рама торчит над куполом; (в) опустить требование свода/ширины — отказ от условий брифа. Процедурное обрамление исключено решением пользователя.

Проверки арки **не добавлены** (узла нет), потому что без решения по модели они либо краснели бы, либо фиксировали заведомо неверную геометрию. Планируемый набор: высота AABB рамы 3.8 (допуск GATE_BOX_EPS), просвет между ногами ≥ 3.5, свод ≥ 3.6, радиус внешних вершин ног ≤ 7.2, коллизии ног и перемычки по AABB меша.

## 3. Стол: поворот

**Состояние до правки:** в сцене стол уже был повёрнут на 90° вокруг Z (`Transform3D(0,-1.05,0, 1.05,0,0, 0,0,1.05, ...)` в построчном формате Godot). `Table` стоял **на торце**: AABB 0.50 × 1.06 × 0.66, высота 1.06 м. Это не «лежит набок». T2-отчёт писал, что стол «поставлен как есть», — это было неверно.

**Глб стола (проверено):** длинная ось X 1.01, высота Y 0.478, глубина Z 0.625. Стол стоит на ножках вдоль Y.

**Сделано:** поворот **на 90° вокруг X** (ось длины остаётся горизонтальной, высота ложится вдоль Z). Бриф говорил «вокруг Z», но поворот вокруг Z ставит стол на торец — это и было текущее состояние. Отклонение от брифа; доказательство — прогон: проверка `стол лежит набок` зелёная, низ AABB 0.0001 м. Альтернатива «вверх ногами» — поворот на 180° вокруг Z — не делал.

Записано в сцене:
- `Table`: `Transform3D(1.05, 0, 0, 0, 0, -1.05, 0, 1.05, 0, 2.95, 0.3208, 4.2)` (столбцы базиса: X=(1.05,0,0), Y=(0,0,1.05), Z=(0,-1.05,0); позиция (2.95, 0.3208, 4.2)).
- `TableBody`: позиция (2.9465, 0.3282, 4.451), `BoxShape3D` 1.0605 × 0.6564 × 0.5019 — совпадает с мировым AABB стола.

Замечание по формату: в `.tscn` 12-значный `Transform3D` читается построчно (`row0 = первые три числа`). Первая попытка писала его по столбцам — проверка `стол лежит набок` дала `false` и низ −0.0148. Это ловится проверкой, поправлено.
