## 4. Геометрия (в нормализованных единицах glTF, метры до масштабирования)

- Треугольники: **50 000** (Godot и Blender совпадают), вершин 30 427, 1 меш, 1 материал (`Material.001`).
- AABB как импортирован (Y-up, пол на Y = 0):
  - X: −0.4227 … +0.4136 → **0.8363**
  - Y: 0 … 0.8710 → **0.8710** (высота)
  - Z: −0.0619 … +0.0592 → **0.1211** (глубина)
- Центр по X ≈ −0.0046 (асимметрия минимальна).

Просвет и свод — замер по вершинам меша (не по AABB). Метод: вершины переведены в Y-up (как в glTF); пол = min Y = 0; центр = середина AABB по X. Для высот y от 0 до 0.68 (ниже перемычки) взяты ближайшие к X=центру внутренние края левой и правой ноги (полоса ±0.004 по Y); ширина = разность.

- **Ширина просвета (между внутренними краями ног):**
  - на полу (y ≈ 0): **0.539**;
  - минимум по высоте ног: **0.533** (на y ≈ 0.087; левый край −0.2693, правый +0.2636).
  - Вдоль высоты ширина держится в диапазоне 0.53–0.56 (внутренние края ног слегка «ходят» по дуге, в низу ~0.27 с каждой стороны).
  - Точность ±0.005 из-за шага выборки по вершинам.
- **Высота внутреннего свода (низ перемычки над полом):** минимальный Y вершин у оси (|X| ≤ 0.05) выше 0.5 → **0.720**. Низ перемычки плоский-ish: по X от −0.14 до +0.12 он на уровне 0.720–0.721, к краям поднимается до ≈0.727 (x≈±0.16), затем у самих ног опускается (x=±0.26 → 0.643, это внутренний угол ноги).

Отношение просвет/свод: 0.539 : 0.720 ≈ 0.75 (вертикальный проём выше, чем широкий, — не квадрат).

## 5. Что это значит для постановки 3.8 м × 3.6 м

Пропорционально одним масштабом не получить оба размера:
- чтобы просвет был 3.8 м: масштаб по X = 3.8 / 0.539 ≈ **7.05** (от 0.533 — 7.13);
- при этом свод окажется 0.720 × 7.05 ≈ **5.08 м**, а не 3.6 м; высота всей арки 0.871 × 7.05 ≈ 6.14 м;
- чтобы свод был 3.6 м: масштаб по Y = 3.6 / 0.720 = **5.0**; тогда просвет 0.539 × 5.0 ≈ 2.70 м.

Значит нужна неравномерная постановка (X ≈ 7.05, Y ≈ 5.0) — то есть арка будет растянута по ширине относительно высоты. Это решение ведущего (см. вопросы), не моё.

## 6. Открытые вопросы

1. **Пропорция.** Просвет 3.8 м и свод 3.6 м одним масштабом не сходятся (свод 5.08 м при просвете 3.8 м). Варианты: неравномерный масштаб (X ≈ 7.05, Y ≈ 5.0, то есть арка вытянута по ширине); либо пересмотреть требования (просвет/свод), либо другая модель. Ведущему решать.
2. **Корневой поворот.** У `arc2_1024.glb` в корне `node_0` поворот +90° по X (меш лежит «по Z»). При постановке в сцену учитывать: масштаб и позиция задаются у инстанса; поворот уже внутри файла.
3. **Точность замера** просвета ±0.005 (выборка по вершинам). Для финальной постановки можно перепроверить в Godot по Y-срезу, если понадобится точнее.
4. **Текстуры:** все 4 слота материала `Material.001` (albedo, metallic, roughness, normal) — 1024×1024. Не проверял, является ли metallic и roughness одной и той же текстурой (в Blender по имени `…_metallic-…_roughness` — скорее всего да).
