## 3. Почему плоский фасад x = 6.5 не сопрягается

- Плоскость x = 6.5 **внутри** пещеры (перед стеной) на h ≲ 3 м: стена на h=0 стоит на x≈6.9, зазор 0.4 м.
- Плоскость x = 6.5 **снаружи** купола на h ≳ 3.3 м: на h=5 купол на x≈5.15, зазор ≈1.35 м
  (на |z|=3 — больше).
- Линия пересечения плоскости с куполом существует только на высотах ~1.9–3.3 м и не образует контура
  фасада от пола до 5.0 м.
- Любая другая плоскость x = const даёт то же: при x = 6.9 (совпадение у пола) зазор на h=5 ≈ 1.75 м;
  при x = 5.15 (совпадение на верху) фасад торчит внутрь пещеры на 1.75 м у пола.

Требование «щели по контуру 0 или ≤ 0.02 м» при плоском вертикальном фасаде от пола до 5.0 м
невыполнимо. Бриф (п. 1) исходил из того, что кривизна купола укладывается в одну плоскость; на
высотах 0 и 5 м это не так. Согласно `AGENTS.md` («если архитектура не вывозит предлагаемое решение,
вернуться к обсуждению с пользователем») и брифу («если зазор не сходится — не двигать молча»)
строю стоп, а не подменяю решение.

## 4. Что это ломает ниже по списку

- **Арка (п. 4):** при x = 6.5 задняя грань ног (6.10) лежит в стене у пола, а перемычка на h = 4.94–6.14
  висит в воздухе перед куполом на ~1 м. «Зазор задней грани ≤ 0.02 м» не выполним при плоском фасаде.
- **Решётка (п. 5):** при x = 6.5 её верх 5.0 м и торцы ±1.9 м упираются в открытую «щель» между
  куполом (внутри 5.15–6.0) и фасадом; пересечения с коллизиями зависят от того, какой пристыковки примем.
  Проверка «решётка пересекает коллизии» сейчас красная (T2-fix3), эта задача её не закрывает без решения.
- **Коллизии (п. 6):** trimesh пересобирается из меша, поэтому зависит от выбранной геометрии сопряжения.

## 5. Варианты для решения пользователя

1. **Плоский фасад + переходная вставка (рекомендую, если вариант 1 сохраняется).** Между контуром
   фасада (плоскость x=6.5) и контуром купола по периметру зоны (|z| ≤ 3, h 0…5) строится лофт-полоса
   (треугольники, соединяющие точки контура фасада и точки купола на том же контуре). Это даёт
   0 щелей, но добавляет наклонные поверхности (до 1.3–1.6 м по X у верха) — вне утверждённого
   варианта «только плоская вставка». Нужно «да».
2. **Фасад по плоскости с перемычкой-козырьком.** Фасад x=6.5 (колонны ±1.9…±3.0 м), сверху козырёк
   от купола (x≈5.15) до фасада (x=6.5) на h=5.0. Закрывает верх, но низ стены у пола остаётся зазором
   0.4 м — то же, что в пункте 1, только с другим контуром.
3. **Фасад на куполе, без плоскости.** Ворота и арка ставятся по кривизне купола (наклон/изгиб
   рамы), без плоского фасада. Отступает от варианта 1.
4. **Плоскость x≈5.15 (по верху).** Фасад у пола выступает внутрь пещеры на 1.75 м — это «коробка»,
   которую пользователь отверг.

Ни один из вариантов не был реализован. Какой выбрать — решение ведущего/пользователя.
