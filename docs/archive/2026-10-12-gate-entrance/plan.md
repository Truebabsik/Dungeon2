# Вход в торговый форпост: закрытые ворота с рычагом — план реализации (ред. 2, реальные ассеты)

> **Для исполнителей:** каждая задача — свежий исполнитель, затем отдельный ревьюер (AGENTS.md). Шаги с чекбоксами `- [ ]`.

**Цель:** зона входа в форпост — пещера-оболочка (купол, световые колодцы, гранит), двор, пандус, арка с решёткой, караулка с рычагом, ход внутрь, реквизит Hunyuan, освещение, проверка в headless.

**Архитектура:** отдельная сцена зоны `game/level/zones/gate_entrance.tscn` (`Node3D`), инстансится в `level.tscn`. Пещера-оболочка — один glb, сгенерированный скриптом Blender (купол, световые колодцы, ровный пол, проём под арку). Реквизит — реальные модели Hunyuan (`*_1024.glb`), поставленные со скалированием и коллизией. Механика: решётка — `AnimatableBody3D` + `portcullis.gd`; рычаг — `Area3D` + `lever.gd`, вызывает `portcullis.open()` через экспорт `NodePath`. Взаимодействие — физическая клавиша `E`.

**Технологии:** Godot 4.7.2, GDScript, Blender 5.2 (генерация оболочки), headless-проверки через `--script`.

**Спецификация:** `docs/current/2026-10-12-gate-entrance/design.md` (включая раздел «Визуальный стиль»).

## Глобальные ограничения

- Пандус: ширина не меньше 4 м; порог ступени не выше 0.2 м.
- Свод купола: высота не ниже 3.5 м; проём решётки открыт не уже 3 м.
- Ход внутрь за караулкой: ширина не меньше 3 м.
- Пол оболочки: ровный, без вертикальных уступов выше 0.1 м; перепады — склоны не круче 45° (вывод спайка 2).
- Капсула персонажа: радиус 0.35, высота 1.8 (как в `Character`).
- Клавиша взаимодействия: `E`, физическая.
- Рейнджер заморожен: `Character`, `FPSCamera`, `character_controller.gd` не меняются.
- Не трогать: пользовательские `MeshInstance3D` (ChainLink, Book1, Cage и др.), модули, `GridMap*`, `mesh_library.tres`, `art/**` (только читать), `.import`.
- Коммит не делать.

## Проверка ревью (риски, которые тесты должны ловить)

1. Решётка закрыта в начале: персонаж не проходит под ней.
2. Рычаг срабатывает только один раз и только в зоне действия.
3. После открытия решётки капсула проходит под аркой на высоте головы без упора.
4. Пандус и пол: капсула едет без подпрыгивания (ступени > 0.2 м) и не проваливается.
5. Световые колодцы дают свет на пол (проверка наличия источников и что пол освещён не нулём).
6. Реквизит не перекрывает проходы: капсула проходит от двора через арку внутрь, не упираясь в жаровню/стойку/вагонетку.
