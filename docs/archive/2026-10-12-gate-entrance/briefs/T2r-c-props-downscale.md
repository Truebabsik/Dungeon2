## Контекст

Пользователь положил четыре сырые модели Hunyuan3D в `art/models/` (текстуры 4096, вес 24–42 МБ).
Нужно получить рабочие пропсы `_1024.glb` (~4–5 МБ), как у существующих пропсов. Метод уже доказан в
`reports/T2-arc2-report.md` — **прочитай его, там точный пайплайн** (импорт glb → даунскейл всех
`bpy.data.images` с max-стороной > 1024 до 1024 пропорционально → экспорт GLB).

**Геометрию НЕ трогать** (никакого декимейта, пересчёта нормалей, ручных правок меша). Только текстуры.
Это консистентно со всеми существующими `_1024`-пропсами и не ломает UV.

## Модели (все в `art/models/`)

| Исходник | Итог |
|---|---|
| `founder_statue.glb` (≈42 МБ) | `art/models/founder_statue_1024.glb` |
| `stall.glb` (≈30 МБ) | `art/models/stall_1024.glb` |
| `arc3.glb` (≈27.9 МБ) | `art/models/arc3_1024.glb` |
| `wall-torch.glb` (≈23.8 МБ) | `art/models/wall-torch_1024.glb` |

Исходники — **только чтение**, не трогать. Каждый итог — отдельный новый файл рядом с исходником.

## Что сделать

1. Напиши переиспользуемый скрипт `game/tools/glb_texture_downscale.py`: принимает список путей к glb,
   для каждого — импорт через `bpy.ops.import_scene.gltf`, даунскейл `bpy.data.images` (max-сторона > 1024 →
   1024, `img.scale`, пропорционально), экспорт `bpy.ops.export_scene.gltf` (`export_format='GLB'`,
   `export_image_format='AUTO'`, `export_apply=True`, `export_yup=True`). Скрипт должен быть параметризован
   (пути вход/выход), не захардкожен под эти 4 файла — он станет основой скилла.
2. Запусти Blender headless (`"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --python ...`)
   на всех четырёх моделях.
3. Замерь и выведи дословно по каждой: тр. ДО/ПО (должны совпасть — геометрия не менялась), список изображений
   с размерами ДО/ПО, итоговый размер файла в байтах.

## Проверка (обязательна)

В `E:\Temp\opencode\props_check\` скопируй по одному итоговому `_1024.glb` (можно все четыре) и `project.godot`,
удали `.godot`, прогони Godot 4.7.2 `--import`, затем `--script` (пример в `reports/T2-arc2-report.md`,
`check_arc2.gd`), который печатает: число мешей/треугольников, AABB (с учётом корневого поворота +90° по X),
размеры текстур по слотам albedo/metallic/roughness/normal. Код возврата 0. Все текстуры должны быть 1024×1024.
Временную папку убери после проверки.
