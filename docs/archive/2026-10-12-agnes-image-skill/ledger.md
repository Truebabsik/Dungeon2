## Открытые вопросы

- **Показ кода шлюзера при 401.** Тело ошибки неверного ключа пришло пустым/не-JSON, поэтому компактный
  `API error {code}: {message}` не собрался; скрипт падает на фоллбэк — текст исключения, код 1.
  **Решение:** не тратить лишний вызов на диагностику, формулировку «показать код и сообщение шлюзера»
  оставить как «если тело ошибки их содержит». Поведение проверено ревьюером.
- **Секрет в грядущем git.** Ключ лежит в `SKILL.md` по решению пользователя. Когда репозиторий появится,
  файл либо уходит в `.gitignore`, либо ключ выносится в переменную окружения — на тот момент потребуется
  отдельное решение (история переписывается задним числом, если файл уже закоммичен).
