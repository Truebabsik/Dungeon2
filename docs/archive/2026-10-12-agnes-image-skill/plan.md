# Скилл генерации изображений Agnes AI (текст → картинка) — план

> **Для исполнителей:** каждая задача — свежий исполнитель, затем отдельный ревьюер (AGENTS.md).

**Цель:** скилл `skills/agnes-image-gen/`, которым агент генерирует арт для Dungeon2 текстом через Agnes AI
(бесплатный text→image), прямым HTTP; плюс рабочий PowerShell-скрипт с проверяемыми кодами возврата.

**Разведку провёл ведущий (2026-10-12, живые пробы ключом).** Вопрос «как устроен API» исполнителю
не переоткрывать — факты ниже.

## Факты API (проверено живьём, не перепроверять без причины)

- База: `https://apihub.agnes-ai.com`, auth: `Authorization: Bearer <key>`.
- `GET /v1/models` (ключ рабочий) отдаёт: `agnes-video-2.5-flash`, `agnes-3.0-flash`, `agnes-image-2.1-flash`,
  `agnes-image-2.0-flash`, `agnes-2.5-flash`, `agnes-image-2.5-flash`.
- `POST /v1/images/generations`, тело `{model, prompt, size, ratio?, return_base64?, extra_body?}`,
  ответ `{data: [{url, b64_json, revised_prompt}], created, task_id}`.
- Проба 1: `model=agnes-image-2.5-flash, size=1K, extra_body.response_format=url` → 10.1 с, url, PNG 534 859 байт, **1024×1024**.
- Проба 2: `size=2K, ratio=3:4` → **1728×2304**.
- Проба 3: `size=1024x768` → пришло **1152×864**: точный `WxH` **не соблюдается**, пропорция сохраняется, размер отмаштабирован.
- Проба 4 (вариант из репо `randomix777/dsh-sprite-gen`): `agnes-image-2.1-flash` + верхнеуровневый `return_base64=true` →
  base64 из 968 240 символов, PNG 1024×1024, `url` в ответе отсутствует.
- `extra_body.response_format` живёт **внутри** `extra_body`, на верхнем уровне — невалидно.
- Допустимые `ratio`: `1:1 3:4 4:3 16:9 9:16 2:3 3:2 21:9`.
- Установленный в dsh плагин `dsh-plugin-agnes-media` даёт инструмент `agnes_image_generate` — скилл описывает
  его как фоллбэк, но основной путь — прямой HTTP (работает в любом харнессе).

## Проверка ревью (риски, которые пробы должны ловить)

1. Скилл обещает команду, которая не работает (расхождение документа и скрипта).
2. Скрипт молча возвращает 0 при ошибке API или проглатывает base64 в консоль (переполнение вывода).
3. Секрет утекает в отчёт, ответ или в файлы вне `SKILL.md`.
4. Скилл обещает точные пиксели, которых API не даёт (см. пробу 3).

## Задачи

### Задача 1: Скилл и скрипт

**Файлы:** `skills/agnes-image-gen/SKILL.md`, `skills/agnes-image-gen/scripts/agnes-image.ps1`.

**Интерфейсы:**
- Produces (скрипт): параметры `-Prompt` (обязательный), `-Size`, `-Ratio`, `-Model`, `-Out`, `-ApiKey`;
  коды возврата `0` успех, `1` ошибка API, `2` ошибка конфигурации; печатает путь, размеры в пикселях, байты, секунды.
- Produces (скилл): фронтматтер `name: agnes-image-gen` + `description`, разделы «когда использовать», ключ,
  быстрый старт, контракт API, размеры, модели, ошибки и лимиты, фоллбэк на `agnes_image_generate`,
  шаблон промпта под арт игры, куда сохранять (`game/assets/generated/`).
- Consumes: ничего из `game/**` и `docs/**`.

- [ ] **Шаг 1: Красная проба.** Скрипт-заглушка (параметры объявлены, тело — `exit 2`); зелёная команда из
      приёмки ниже обязана покраснеть. Дословный вывод — в отчёт.
- [ ] **Шаг 2: Реализация.** Скрипт по контракту, затем `SKILL.md` с дословно проверенными командами.
- [ ] **Шаг 3: Зелёные пробы 1–4** (см. приёмку). Дословные выводы — в отчёт.
- [ ] **Шаг 4: Ревью** отдельным агентом (ведущий запускает).

**Приёмка (пробы):**

1. `.\skills\agnes-image-gen\scripts\agnes-image.ps1 -Prompt 'a red cube on white background, minimal flat illustration' -Size 2K -Ratio 3:4 -Out E:\Temp\opencode\probe-t1.png` → код 0, файл существует, это PNG, размер ровно 1728×2304.
2. Ключ не задан ни в `-ApiKey`, ни в `$env:AGNES_API_KEY` → код 2, сообщение про ключ, ни одного HTTP-запроса.
3. `-ApiKey 'sk-invalid'` → код 1, в stderr код/сообщение шлюзера, без JSON-стека.
4. `-Size 1K -Ratio 21:9 -Out E:\Temp\opencode\probe-t4.png` → код 0, соотношение сторон ±2 %.

## Что не входит в план

- Image-to-image / референсные изображения (скилл может упомянуть формат, но не реализует и не проверяет).
- Генерация видео (`agnes-video-2.5-flash`).
- Автоматический ресайз под точные пиксели и вырезание фона (отдельная задача, если понадобится).

## Самопроверка

- Приёмка покрывает цель: команда из скилла генерирует файл (п. 1), ошибки различимы (п. 2–3), пропорции работают (п. 4).
- Секрет: ключ только в `SKILL.md`.
- Область не пересекается с активной задачей `2026-10-12-gate-entrance`.
