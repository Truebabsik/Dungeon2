## Находки

**Critical: 0**

**Important: 0**

**Minor: 3**

1. `SKILL.md:3` — description гибридный: «Use when нужны сгенерированные изображения...».
   Бриф требовал скилл «по-русски». На роутинг и работу не влияет — косметика.
2. `agnes-image.ps1` — файл UTF-8 без BOM, при этом 9 комментариев на русском (стр. 10-12, 20, 36, 57,
   88, 105, 122, 130). PS 5.1 читает no-BOM как ANSI-кодовую страницу: в trace/ISE комментарии будут
   mojibake. Функционально безвредно (все сообщения для вывода — по-английски, парсинг не ломает;
   пробы A/B доказали), но при желании вычистить — добавить BOM или оставить ASCII-комментарии.
3. `agnes-image.ps1:98-103` — ветка «без `-Out` — печатать только url» не покрыта ни одной пробой
   (исполнитель тратил лимит на приёмку, я — на приёмку тоже). Код шестистрочный и тривиальный,
   ответ API уже разобран до этой ветки пробой B; риск минимален, но формально это единственная
   непрогнанная ветка контракта. (Ветка создания каталога 106-110 проверена отдельным прогоном тех же
   выражений — работает.)

## Заметки для ведущего (не находки T1)

- **Оговорка 2 исполнителя закрыта**: env-путь ключа из быстрого старта SKILL.md проверен моей пробой B
  дословно (кроме значения `-Out`, что на контракт не влияет).
- **git в будущем**: корень не является git-репозиторием, поэтому «не коммитить» сейчас защищает
  только осторожность. В момент `git init` файл с ключом (`SKILL.md:18`) попадёт в индекс — тогда
  нужен `.gitignore` либо ротация ключа. Решение о хранении ключа в скилле — за ведущим (plan.md:34),
  исполнитель его строго соблюл.
- **IHDR vs System.Drawing**: обоснование исполнителя (отчёт:21) принял; если PowerShell-скриптов
  станет больше, вариант «файл без BOM + русские комментарии» (Minor №2) стоит тогда же зафиксировать
  в `docs/agents/constraints.md` — о чём исполнитель, кстати, сам написал (отчёт:153).
