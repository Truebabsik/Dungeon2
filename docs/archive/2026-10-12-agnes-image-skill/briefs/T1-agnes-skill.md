## Где это в проекте

Проект — Godot 4.7.2 `F:\WORK\Dungeon2`, арт пока на заглушках. Пользователь дал ключ к бесплатному
text→image сервису Agnes AI. Задача — скилл `skills/agnes-image-gen/`: инструкция для агента + рабочий
PowerShell-скрипт, чтобы генерировать картинку одной командой. Интерфейс API проверен ведущим живьём,
факты — в `docs/current/2026-10-12-agnes-image-skill/plan.md`. **Вопрос «как устроен API» не переоткрывай**
и не перепроверяй эндпоинты — бери из плана.

## Что сделать

**1. `skills/agnes-image-gen/scripts/agnes-image.ps1`** (PowerShell 5.1+, `param` в начале файла):

- Параметры: `-Prompt` (обязательный), `-Size` дефолт `2K`, `-Ratio` дефолт `1:1`,
  `-Model` дефолт `agnes-image-2.5-flash`, `-Out` (путь к `.png`; без него — только вывести url),
  `-ApiKey` дефолт `$env:AGNES_API_KEY`.
- Запрос: `POST https://apihub.agnes-ai.com/v1/images/generations`, заголовок `Authorization: Bearer <key>`,
  тело `{model, prompt, size, ratio, extra_body: {response_format: "url"}}`, таймаут 300 с.
- При успехе: скачать `data[0].url` в `-Out` (каталог создать), вывести путь, размеры в пикселях, байты,
  секунды. Base64 в вывод не выводить никогда.
- Коды возврата: `0` успех; `1` ошибка API (разобрать оба формата шлюзера `{code,message}` и `{error:{code,message}}`,
  напечатать в stderr компактно, без stack trace); `2` ошибка конфигурации (нет ключа, пустой prompt,
  `ratio` вне списка).
- `ratio` валидировать локально до запроса: `1:1 3:4 4:3 16:9 9:16 2:3 3:2 21:9`.
- Размеры в пикселях читай из заголовка PNG (IHDR) или `System.Drawing` — на твоё усмотрение, обоснуй в отчёте.

**2. `skills/agnes-image-gen/SKILL.md`** (≤ 7 КБ, по-русски, команды дословно те, что проверены пробами):

- Фронтматтер `name: agnes-image-gen` и `description` (когда применять: арт, иконки, текстуры, концепты для Dungeon2).
- Разделы: когда использовать; ключ (значение `sk-6m9...` — полный ключ в файле, с пометкой «секрет,
  не публиковать и не коммитить»); быстрый старт (одна команда скрипта); контракт API (эндпоинт, auth, тело, ответ);
  размеры (тир `1K/2K/3K/4K` + таблица реальных размеров из плана и предупреждение, что точный `WxH` не соблюдается);
  модели (список из `/v1/models`); ошибки и лимиты (не ретраить автоматически — генерация не идемпотентна);
  фоллбэк: инструмент dsh `agnes_image_generate` (`prompt`, `size`, `ratio`, `output=file|url|base64`, `saveDir`);
  шаблон промпта под арт игры; куда сохранять (`game/assets/generated/`, пробы в `E:\Temp\opencode`).
- Base64 в выводе не показывать; про это же напиши в скилле как про ловушку.
