# Итог: скилл генерации изображений Agnes AI

**Готово:** `skills/agnes-image-gen/` — скилл (SKILL.md) + PowerShell-скрипт, генерируют арт для Dungeon2
текстом через бесплатный Agnes AI прямым HTTP.

**Что умеет:** один вызов → PNG в `game/assets/generated/` (или только url), тиры `1K/2K/3K/4K` + 8 пропорций,
коды возврата `0/1/2`, разбор ошибок шлюзера в обеих формах, base64 никогда не печатается. Фоллбэк —
инструмент dsh `agnes_image_generate`.

**Проверено живьём:** 2K/3:4 → 1728×2304; 1K/21:9 → 1568×672; без ключа → код 2 без HTTP; неверный ключ →
код 1 компактно; ветка без `-Out` → url + 9,5 с. Пробы исполнителя и независимые пробы ревьюера сошлись.

**Ревью:** `assessment: Да`, Critical 0 / Important 0 / Minor 3 — все три закрыты (см. `ledger.md`).

**Ограничения, о которых надо помнить:**

- Точный размер в пикселях API не отдаёт (`1024x768` → `1152×864`) — ресайзить вручную.
- Прозрачный фон не гарантируется, image-to-image в скилле не реализован.
- Ключ лежит в `SKILL.md` (решение пользователя) — при появлении git это требует отдельного решения.

Папка задачи уезжает в `docs/archive/2026-10-12-agnes-image-skill/`.
