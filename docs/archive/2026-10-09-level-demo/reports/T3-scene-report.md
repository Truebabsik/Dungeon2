## Расчёт `size` камеры из `MODULES`

Из `game/level/level_map.gd` (312 записей):
- минимум `cell.x` = -1 (лестница `stairs` в `Vector2i(-1, 4)`), максимум `cell.x` = 14 (стены `rot 90` в `x=14`);
- минимум `cell.y` = 0, максимум `cell.y` = 12 (стены `rot 0` в `(6..13, 12)`).

Диапазон по X: (14 - (-1) + 1) = 16 клеток → 16 × 4 = 64 м. По Y: (12 - 0 + 1) = 13 клеток → 52 м.
Берётся большая сторона: `size = 64.0` (ортографическая камера с `keep_aspect` по высоте задаёт вертикальный размер кадра в метрах).

## Позиция камеры: отклонение от брифа

Бриф: `position = Vector3(0, 40, 0)`. **Проверено прогоном: при этой позиции план не попадает в кадр.**
Ортографическая камера центрирована на своей оси. Ось при поворотах (-35°, 45°) из точки (0, 40, 0) пересекает
землю в точке ≈ (-40.4, 0, -40.4), а центр плана ≈ (28, 0, 26). Проба с позицией (0, 40, 0) (окно 64×64, 1 px = 1 м):
план по экрану занимает x ∈ [-7.6, 74.4], y ∈ [59.9, 110.2] при кадре [0, 64] × [0, 64] — большая часть плана вне кадра.

Решение: сохранена высота 40 и поворот, позиция смещена так, чтобы ось камеры проходила через центр плана
Q = (28, 0, 26) (центр по X: (-4 + 60)/2 = 28; по Z: (0 + 52)/2 = 26). Расчёт: смещение от Q вдоль
обратного направления взгляда при высоте 40 и наклоне 35°: t = 40 / sin 35° ≈ 69.74; горизонтальная составляющая
t · cos 35° ≈ 57.12, по осям X и Z — ×cos 45° ≈ 40.39. Позиция = Q + (40.39, 40, 40.39) = (68.39, 40, 66.39).

## Решения вопреки брифу

1. `position` камеры: `(68.39, 40, 66.39)` вместо `(0, 40, 0)` — по доказательству выше.
   Высота 40, поворот, `size` и остальные параметры — как в брифе.
2. `rotation_degrees` и `position` записаны в `.tscn` как свойства (без пересчёта матрицы `transform`).
   Godot загрузил и применил их: проба показывает `rot=(-35, 45, 0)` и `position=(68.39, 40, 66.39)`.
3. `Camera3D` — дочерний узел корня `Level`, а не отдельный узел. В брифе формулировка «не `Level`» противоречила тому, что корень сцены и есть `Level`. Решение ведущего: оставить как есть.
4. Счёт детей корня 314 вместо 312: 312 модулей плюс `DirectionalLight3D` и `Camera3D`. Это ожидаемо.
5. Проба кадра выполнена при явном окне 1152×648: headless по умолчанию даёт 64×64, поэтому проверка кадра без окна ненадёжна. Грабли среды.
