## 4. Выбор size и position

**Конфликт требований.** Бриф требует одновременно (а) план ≥ 85 % ширины кадра и (б) запас ≥ 0.5 по высоте сверху и снизу.
- Для (б): size ≥ 47.33 + 2·0.5 = **48.33**.
- Для (а): ширина кадра = size·16/9 ≤ 62.93 / 0.85 = 74.04 → size ≤ **41.66**.
Ограничения несовместимы: при size ≤ 41.66 по высоте план обрезается примерно на 2.8 единицы сверху и снизу. Обрезка плана — не то, что исполнитель вправе выбирать молча, поэтому выбран вариант «весь план в кадре». **size = 48.5** (запас по высоте 0.59 сверху и снизу, 0.59 = (48.5 − 47.33)/2). Ширина плана: 62.93 / (48.5·16/9) = **73.0 %**.

**position.** Центр плана в мире на y = 0: из R_mid и U_mid: x − z = 12, x + z = 49.17 → C = (30.59, 0, 18.59).
Камера на y = 40: P = C + t·(0.5, 0.7071, 0.5), t = 40 / 0.7071 = 56.57 → P = (58.87, 40, 46.87).
Проверка проекцией: R(P) = 0.7071·(58.87 − 46.87) = 8.485 = R_mid ✓; U(P) = −0.5·105.74 + 0.7071·40 = −52.87 + 28.28 = −24.59 = U_mid ✓.

- **85 % ширины не выполнено (73 %).** Требование несовместимо с запасом по высоте (см. раздел 4). Выбран полный кадр плана. Если пользователю важнее крупный план, нужна обрезка по высоте или другой ракурс/соотношение кадра — это решение ведущего.
