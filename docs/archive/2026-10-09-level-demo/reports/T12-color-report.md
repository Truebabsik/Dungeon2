## Расчёт: прототипы вне кадра

Данные: `Camera3D` с `transform` из файла (position `(58.87, 40, 46.87)`, rotation `(-45, 45, 0)`), `projection = 1` (ортографическая), `size = 48.5`. Разрешение кадра 1152×648, соотношение 16:9.

Базис камеры, по строкам `Transform3D`:
- вправо `R = (0.7071, 0, -0.7071)`
- вверх `U = (-0.5, 0.7071, -0.5)`
- вперёд `F = (-0.5, -0.7071, -0.5)`

Полувысота кадра `24.25`, полуширина `24.25 × 16/9 ≈ 43.1`.

Точка прототипа `(x, y, z)` в мировых координатах: `x = -40`, `y ≈ 0`, `z` от `0` (floor_tile_large) до `78` (stairs). Для `d = p − c`:
- `d·R = 0.7071·(dx − dz) = 0.7071·(−98.87 − (z − 46.87)) = −0.7071·(52 + z)`.
- `d·U = −0.5·dx + 0.7071·dy − 0.5·dz = 49.435 − 28.28 + 23.435 − 0.5z = 44.59 − 0.5z` (при `y = 0`).

Условие видимости: `|d·R| ≤ 43.1` и `|d·U| ≤ 24.25`.
- По горизонтали: `|52 + z| ≤ 60.95`, то есть `z ≤ 8.95`.
- По вертикали: `|44.59 − 0.5z| ≤ 24.25`, то есть `z ≥ 40.68`.

Оба условия одновременно не выполняются ни при каком `z` из диапазона `[0, 78]`. Ближайший к кадру прототип `wall` (`z = 6`) даёт `d·U ≈ 41.6`, что выше верхней границы кадра (24.25) примерно на 17 единиц. Высота мешей прототипов несколько единиц, так что такой отрыв не закрывается. Прототипы вне кадра.

Для сравнения: при старом `x = -20` условие даёт `z ∈ [20.7, 28.9]`, то есть попадает `barrel_large` (`z = 24`). Это совпадает с находкой ревью T11, и модель согласуется с ней.
