## Что не вошло и почему

- `wall_corner` — не использован. Геометрия стен (1 м толщина, центр на грани, длина 4 м) даёт перекрытие в углах клеток,
  отдельная модель угла не нужна для базовой раскладки. Проверить визуально в задаче 5.
- `torch_mounted`, `wall` с поворотом 180/270 — не использованы. Факелы без точной привязки к стене выглядели бы «висящими» в центре клетки.
- Остальные 16 `kind` из списка задачи 1 использованы. Нужных вне списка моделей не потребовалось, `NEEDS_CONTEXT` не возникал.

Раскладка приближённая (по `art/reference/reference.png`, изометрия переведена в план вручную и упрощённо): сверка — задача 5.

## Решения вопреки брифу

1. Путь к Godot: в брифе `F:\WORK\Godot_v4.7.2-stable_win64_console.exe`, на диске — каталог с тем же именем, внутри консольная версия (см. выше).
2. Вместо литерального написания 312 записей вручную `level_map.gd` сгенерирован временным скриптом из таблицы комнат, дверей,
   окон и реквизита. Результат — обычный литерал `const MODULES: Array = [...]`, последующие правки делаются в нём напрямую.
   Генератор удалён, чтобы не появился второй источник истины.
3. Поворот стены на 180/270 (брифом не определён): трактуется по оси (`rot % 180`), центр остаётся на той же грани. Сейчас в `MODULES` таких записей нет.
4. Для `wall*` при `rot 0` смещение по X на `HALF`, при `rot 90` по Z на `HALF` — как в брифе. Для пола и прочего — центр клетки.
5. Лестницы `stairs` — центр клетки, без пола под ними. Пол в клетке `(12, 7)` сохранён (лестница стоит поверх), у `(-1, 4)` пола нет (клетка вне плана). Геометрия лестницы не проверялась — сверка в задаче 5.
