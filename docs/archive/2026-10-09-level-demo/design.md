# Дизайн: демо-уровень подземелья (Godot)

Статус: **утверждён 2026-10-09** (разделы 1–3 в диалоге). Область этапа: **только уровень**, без игрока.

## Цель

Собрать в Godot 4.7 статичную сцену подземелья, повторяющую план `art/reference/reference.png` по раскладке комнат, коридоров, лестниц, дверей и реквизита. Источник геометрии — `.gltf` из `art/KayKit_Dungeon_Pack_1.1_FREE`.

## Структура (раздел 1)

- `game/` — проект Godot 4.7 (`project.godot`).
- `game/assets/kaykit/` — только используемые `.gltf`, их `.bin` и текстуры, плюс `License.txt`. Оригинал в `art/` не меняем.
- `game/level/level_map.gd` — данные уровня: сетка клеток и список модулей (тип, клетка, поворот). Без нод.
- `game/level/level_builder.gd` — `Node3D`, который по данным создаёт инстансы `.gltf`.
- `game/level/level.tscn` — сцена: билдер, свет, ортографическая камера.

## Сетка и размещение (раздел 2)

- Размеры проверены по файлам: `wall.gltf` — 4 м ширина, 1 м толщина, 4 м высота; `floor_tile_large.gltf` — 4×4 м.
- Клетка сетки = 4 м. Пол — в центре клетки. Стена — на грани клетки, центр стены на границе.
- Поворот стены по X или Z задаётся полем модуля.
- Модули не расставляются в сцене вручную: билдер читает карту.
- Камера: ортографическая, поворот 45° по Y, около 35° к горизонту.
- Раскладка из `reference.png` переносится в данные вручную; сверка с референсом — на этапе проверки.

## Проверка и границы (раздел 3)

- **Автоматическая (headless).** `godot --headless --path game --script ...` проверяет: все пути `.gltf` существуют; число созданных модулей равно числу записей карты; сцена собирается без ошибок. Вердикт — код возврата процесса.
- **Визуальная.** Скриншот сцены рядом с `reference.png`, сверка по комнатам, лестницам и дверям.
- **Вне объёма.** Игрок, управление, камера-follow, освещение сверх базового, интерактив, сохранения.

## Порядок работ

1. `game/project.godot` и копирование нужных `.gltf` в `game/assets/kaykit/`.
2. `level_map.gd` и `level_builder.gd`.
3. `level.tscn`.
4. Headless-проверка.
5. Визуальная сверка с `reference.png`.

## Ограничения (из `docs/agents/constraints.md`)

- Табы для отступов, английские идентификаторы, русские комментарии и имена тестов.
- Никаких `class_name` в `game/level/`: использовать `const X := preload("res://...")`.
- Ворота — `failed: 0`, а не число проверок.
- `level_map.gd` не знает о нодах: только `RefCounted` или константы данных.
