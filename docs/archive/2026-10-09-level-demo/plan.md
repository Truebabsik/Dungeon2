# Демо-уровень подземелья: план реализации

**Спецификация:** [design.md](design.md) (утверждена 2026-10-09).
**Исполнение:** по `AGENTS.md` — субагенты: исполнитель пишет, отдельный ревьюер проверяет диф и бриф.

**Цель:** статичная сцена Godot 4.7, повторяющая план `art/reference/reference.png` по раскладке.
**Ассеты:** KayKit Dungeon Pack, `game/assets/kaykit/`.

## Глобальные ограничения

- Размер клетки сетки: **4 м**. Стена: 4 м ширина, 1 м толщина, 4 м высота. Пол: 4×4 м.
- Камера: ортографическая, поворот **45°** по Y, наклон **35°** к горизонту.
- Табы для отступов; идентификаторы английские, комментарии и имена тестов русские.
- В `game/level/` без `class_name`: только `const X := preload("res://...")`.
- `level_map.gd` не знает о нодах.
- Ворота проверок: `failed: 0`, число проверок в ожиданиях не фиксировать.
- Вердикт headless-проверки — код возврата процесса (`0`/`1`/`2`), stderr вердиктом не является.

## Задачи

### Задача 1. Проект Godot и ассеты

**Файлы:** создать `game/project.godot`; скопировать ассеты в `game/assets/kaykit/`.

**Интерфейсы:**
- Производит: путь ассетов `res://assets/kaykit/<имя>.gltf`.

Шаги:
- [ ] Создать `game/project.godot` с версией Godot 4.7 и главной сценой `res://level/level.tscn` (сцена появится в задаче 3).
- [ ] Скопировать в `game/assets/kaykit/`: `floor_tile_large`, `wall`, `wall_corner`, `wall_doorway`, `wall_archedwindow_open`, `stairs`, `pillar`, `table_medium`, `chair`, `barrel_large`, `bed_frame`, `chest`, `shelves`, `coin_stack_small`, `torch_mounted`, `banner_patternA_red`, `License.txt`. Состав расширяется в задаче 3, если раскладка потребует других моделей.
- [ ] Для каждого `.gltf` прочитать поле `uri` в JSON и скопировать все внешние `.bin` и текстуры, на которые он ссылается. Отсутствующий `uri` = ошибка копирования.
- [ ] Проверка: `Godot_v4.7.2-stable_win64.exe --headless --path game --import` завершается с кодом `0`.

### Задача 2. Данные карты и билдер

**Файлы:** создать `game/level/level_map.gd`, `game/level/level_builder.gd`.

**Интерфейсы:**
- Производит: `level_map.gd` — `const MODULES: Array` элементов `{ "kind": String, "cell": Vector2i, "rot": int }`, где `rot` — 0, 90, 180 или 270; `const CELL_SIZE := 4.0`.
- Производит: `level_builder.gd` — `func build() -> int` возвращает число созданных инстансов.
- Потребляет: `MODULES` и `CELL_SIZE` из `level_map.gd` (этой же задачи), пути `res://assets/kaykit/<kind>.gltf` из задачи 1.

Шаги:
- [ ] Написать тест `game/tests/level_check.gd`, который вызывает `build()` и проверяет, что число инстансов равно `MODULES.size()`. (Тест пишется в задаче 4; здесь фиксируем только интерфейс.)
- [ ] Реализовать `level_map.gd`: `MODULES` с раскладкой по `reference.png` (записи вида `{ "kind": "floor_tile_large", "cell": Vector2i(0, 0), "rot": 0 }`).
- [ ] Реализовать `level_builder.gd`: для каждой записи загрузить `res://assets/kaykit/<kind>.gltf`, создать инстанс, поставить в `cell * CELL_SIZE + смещение`, повернуть на `rot`. Пол — центр клетки; стена — грань клетки.
- [ ] Проверка: `build()` возвращает `MODULES.size()`.

### Задача 3. Сцена и камера

**Файлы:** создать `game/level/level.tscn`.

**Интерфейсы:**
- Потребляет: `level_builder.gd` из задачи 2.

Шаги:
- [ ] Собрать сцену: узел `Node3D` с `level_builder.gd`, направленный свет, `Camera3D` в режиме ортографической проекции с поворотом 45° по Y и 35° к горизонту. Главная сцена проекта — эта сцена.
- [ ] Открыть сцену headless и убедиться, что ошибок загрузки нет (код возврата `0`).

### Задача 4. Headless-проверка

**Файлы:** создать `game/tests/level_check.gd`.

**Интерфейсы:**
- Потребляет: `level_map.gd` (`MODULES`), `level_builder.gd` (`build()`).

Шаги:
- [ ] Написать проверку: для каждой записи `MODULES` файл `res://assets/kaykit/<kind>.gltf` существует; `build()` возвращает `MODULES.size()`; ошибки не накапливаются. Вывод: `failed: N`.
- [ ] Запуск: `Godot_v4.7.2-stable_win64.exe --headless --path game --script res://tests/level_check.gd`. Ожидаемо: `failed: 0`, код возврата `0`.

### Задача 5. Визуальная сверка

**Файлы:** правка `game/level/level_map.gd` при расхождениях.

Шаги:
- [ ] Сделать скриншот сцены (`level.tscn`), положить в `docs/current/2026-10-09-level-demo/reports/`.
- [ ] Сверить с `art/reference/reference.png` по комнатам, коридорам, лестницам и дверям. Расхождения исправить в `MODULES`, затем повторить задачу 4.

## Review Focus

- Отсутствующий внешний `.bin` или текстура у копируемого `.gltf` — покрывается задачей 1 (проверка `uri`).
- Модель в `MODULES` без файла `.gltf` — покрывается задачей 4.
- Поворот `rot` не 0/90/180/270 — покрывается задачей 2 (валидация значения в `build()`).
- Пустая `MODULES` — покрывается задачей 4: `build()` возвращает 0, и проверка должна явно зафиксировать это как пустой уровень, а не как успех по умолчанию.
- Загрузка сцены без главной — покрывается задачей 3.

## Порядок и зависимости

Задачи 1 → 2 → 3 → 4 → 5, строго последовательно: каждая потребляет интерфейсы предыдущей.
