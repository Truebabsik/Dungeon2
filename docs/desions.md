# Решения

## 2026-10-09 — способ сборки уровня

- **Варианты:** (а) данные уровня в коде + сцена из `.gltf`; (б) GridMap из MeshLibrary; (в) ручная раскладка узлов в `.tscn`.
- **Выбрано:** (а). Раскладка читаема в диффе, проверяема headless, не привязана к редактору.
- **Отвергнуто:** (б) — реквизит и декор не ложатся в сетку; (в) — трудно править и сверять с референсом.

## 2026-10-09 — где хранить ассеты

- **Варианты:** (а) копировать нужные `.gltf` в `game/`; (б) копировать весь пак; (в) ссылаться на `art/` напрямую.
- **Выбрано:** (а). Godot загружает только ресурсы внутри `res://`.
- **Отвергнуто:** (б) — лишние файлы в проекте; (в) — невозможно в Godot.
